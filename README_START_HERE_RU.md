# Project Kingdom — старт разработки игрового ядра

Текущая версия: **0.1.0-stage0-voice3.3** для Minecraft 1.20.1 / Forge 47.3.0 / Java 17.

Это единый проект мода `kingdomnpc`. Существующие NPC, территории, физическая экономика, банк, предприятия и мастерские сохранены. Поверх них создан фундамент большого пути игрока: от учётной записи лаунчера и первого входа до будущего государства и династии.

## Что реализовано на этапе 0

- Серверная модель `AccountId → один активный CharacterId → DynastyId`. Minecraft UUID считается только идентификатором текущей сессии и может безопасно измениться.
- Сохранение идентичности в мире и повторная привязка новой сессии без создания второго персонажа.
- Одноразовый шлюз токенов лаунчера с проверкой срока действия и защитой от повторного использования.
- Защищённый режим разработки: обход авторизации возможен только при одновременном включении флага сборки и флага запуска.
- Последовательные миграции данных с закрытием входа при ошибке.
- Политика первого появления: Avalon имеет приоритет, при его отсутствии игрок попадает на обычный спавн и вход не блокируется.
- Постоянная «Книга игрока»: выдаётся при входе, восстанавливается после возрождения или потери, не выбрасывается и не размножается.
- В Книге постоянно видны шесть разделов: Игрок, Банк, Капитал, Государство, Династия, Мир.
- Банк и общий капитал читают реальные данные существующей экономики Stage 1. Государство, Династия и Мир явно показаны как подготовленные, но ещё не подключённые разделы.
- Ошибка необязательного модуля изолируется и не выключает ядро.
- Интерфейс платёжного провайдера существует, но безопасная реализация по умолчанию всегда отклоняет пополнение.

## Важная граница

В этом репозитории находится **игровое ядро Forge**, а не приложение лаунчера. Внешняя платформа должна позже передать одноразовый токен через отдельный сетевой адаптер. Реальный платёжный провайдер, форма пополнения в лаунчере и подтверждение платежей будут подключены в самом конце, как и было согласовано.

До подключения внешнего адаптера производственный проверяющий токенов ничего не принимает. Это намеренное безопасное поведение, а не временная авторизация по нику или Minecraft UUID.

## Сборка и проверка

```bash
./gradlew clean test build
python3 03_verify_project.py
bash validation/stage1_harness/run.sh
```

Готовый файл:

`build/libs/kingdomnpc-0.1.0-stage0-voice3.3.jar`

Для Windows можно запустить `01_build_windows.bat`, затем `02_install_windows.bat`. Перед установкой закрой игру и сделай резервную копию тестового мира. Не устанавливай ZIP в папку `mods` — нужен только собранный JAR.
