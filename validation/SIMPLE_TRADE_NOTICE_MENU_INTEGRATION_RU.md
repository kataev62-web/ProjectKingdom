# Подключение простой продажи к заявке — 16.10.2026

В `KingdomSimpleTradeMenu.openForNotice(...)` добавлена серверная привязка меню к объявлению BUY:
- объявление принадлежит конкретному предприятию;
- ID предмета разрешается через реестр Minecraft;
- цена берётся из объявления, не из руки игрока;
- перед продажей повторно проверяется оставшееся количество и неизменность цены;
- после обмена уменьшается остаток информационного объявления.

Вызов openForNotice ещё необходимо подключить к действию на игровом блоке/предприятии. Нет проверенной сборки Forge и игрового теста. Существующий обмен через обычные контейнеры не гарантирует атомарность при аварийном отключении JVM. Поддерживается только оплата медными монетами одного номинала. Объявление по-прежнему только информационное.

Проверено: javac + SimpleLocalTradeServiceTest — 19 checks PASS. Код меню зависит от Forge/Minecraft и локально не компилировался.
