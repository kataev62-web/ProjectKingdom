# Этап 1: пороги сырья и готовой продукции

Добавлен `EnterpriseStockPolicy`: чистая Java-логика без генерации предметов и денег.

- Готовая продукция: включение производства при остатке <= minimum; остановка при >= maximum; между порогами сохраняется предыдущее состояние.
- `productionBatch` ограничивает выпуск свободным местом до maximum. Реальные ингредиенты и рабочее время должен проверять исполнитель рецепта TFC.
- Сырьё: заявка на доске потребностей создаётся при физическом остатке < minimum, с целевым пополнением до maximum; уже подтверждённые поставки вычитаются из потребности.
- Агрегация нескольких складов, резервирование товара, учёт порчи, сохранение состояния производства, связь с доской потребностей и Forge — ещё не подключены.
- Испытано отдельно через javac/java: EnterpriseStockPolicyTest.
