# Простая торговля — проверка готовности (16.10.2026)

Сценарий: игрок кладёт руду в слот, нажимает «Продать», получает физические монеты из кассы; руда переходит на склад.

## Реализовано в исходниках
- `KingdomSimpleTradeMenu`: интерфейс на базе ChestMenu, торговый слот, кнопка, физические контейнеры, проверка товара/места/монет.
- Блокировка склада и кассы в рамках одного JVM, откат при Java-исключении.
- Дополнительные проверки: передача предметов теперь завершается ошибкой, если в источнике/приёмнике фактически перемещено меньше требуемого; такая ошибка вызывает откат снимков в рамках JVM.
- `SimpleTradeMenuSale`: автономный Java-контракт; `SimpleTradeMenuSaleTest` PASS.

## НЕ завершено — не называть готовой игровой механикой
- Нет проверенного пути открытия этого меню из NPC/предприятия; `KingdomSimpleTradeMenu.open` не вызывается игровым событием.
- `onSold` пока только Runnable, не связывает конкретное количество с заявкой.
- Нет доказанной совместимости и компиляции Forge 47.3.0; нет теста в Minecraft.
- Нет безопасной транзакции через отключение питания между записью нескольких контейнеров.
- Отдельно проверить реальные слоты/клики, разграничение прав, расстояние до предприятия и номиналы монет.

Принцип: не вводить новую сложную экономику. Только простой торговый слот и реальные монеты.
