# Постоянный каталог доски потребностей

Добавлен DurableDemandBoardCatalog: атомарная замена файла снимка, CRC32, проверка структуры, восстановление объявлений и идентификаторов уже подтверждённых поставок. Ошибочный файл приводит к IOException, не к тихому обнулению.

Критическое ограничение: acknowledgeCommitted разрешено вызывать ТОЛЬКО после подтверждённого физического обмена монет на товар через торговый координатор. Если сервер выключился между физическим обменом и записью каталога, нужна сверка по идентификатору операции в торговом журнале до повторного подтверждения. Каталог не является источником истины для физического инвентаря. Подключение к игровому блоку, событиям NPC, ForgeGradle и игровая проверка ещё не выполнены.
