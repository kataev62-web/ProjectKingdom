# Локальная продажа по объявлению — статус

Добавлен SimpleTradeNoticeSettlement: серверная операция продажи по BUY-заявке с проверкой ID, покупателя, количества, цены, товара и денег. Доска информационная; торговля только на месте. Подтверждённая продажа уменьшает сохранённую заявку.

Тест: javac + SimpleTradeNoticeSettlementTest — PASS (7 checks).

ОГРАНИЧЕНИЯ: PhysicalTrade — порт, а не привязка к Minecraft ItemStack. Forge GUI и игровое взаимодействие пока не подключены к данному сервису. Контракт transfer(false) требует отсутствия частичных изменений. При краше между физической передачей и сохранением объявления автоматической атомарности нет. Не считать блок завершённым до Forge сборки и игрового теста.
