# Физическая поставка по доске потребностей — промежуточный компонент

Добавлен DemandDeliveryCoordinator: проверка цены/физической кассы, durable pending до физической операции, проверка результатов, сохранение исполнения заявки, запрет повторной выдачи по тому же delivery UUID. При аварии или ошибке pending остаётся и требует ручной сверки.

**Не готово к игровому использованию:** PhysicalExchange — интерфейс, реальный Forge-адаптер физического обмена ItemStack/монет ещё не подключён. Нет глобальной межпроцессной блокировки по предприятию/заявке, резервирования монет и товара, восстановления после ошибки между физической операцией и записью доски. Нельзя использовать данный класс как единственный барьер конкурентных поставок. До интеграции с общей блокировкой предприятия и карантином торговли физические сделки должны быть выключены.

Тест: javac + java DemandDeliveryCoordinatorTest; проверки лимита цены, отсутствия монет, аварийного карантина, перезапуска, успешного подтверждения, дубля.
