# Project Kingdom: единая локальная торговля — состояние

## Подтверждено локальными Java-тестами
- Объявления BUY и SELL информационные; сделка проводится только у предприятия.
- Торговля привязана к конкретному предприятию и точному registry ID товара.
- Количество и стоимость ограничены сохранённым объявлением.
- BUY: товар от посетителя предприятию, монеты от предприятия посетителю.
- SELL: товар от предприятия посетителю, монеты от посетителя предприятию.
- Частичная сделка уменьшает остаток объявления; изменения сохраняются на диск.
- Список объявлений конкретной торговой точки доступен без обхода мира и без тиковых задач.
- При неопределённом результате обмена дальнейшие сделки блокируются в экземпляре сервиса.

## Не готово / нельзя считать завершённым
- PhysicalExchange — интерфейс, тестовый порт имитирует инвентари; реальная связка с ItemStack и GUI не проверена.
- Нет гарантированной атомарности между изменением игровых контейнеров и записью объявления при падении JVM.
- Защита от повторного обмена после перезапуска должна быть реализована в игровом интеграционном слое.
- Не проведена полная сборка Forge и проверка на Minecraft сервере.
- Для торговли разными номиналами монет нужен реальный физический порт, не виртуальные балансы.

## Архитектура
Одна доска (только сведения) → игрок приходит к предприятию → меню с точным ID → локальный физический обмен → изменение объявления по событию. Без фонового сканирования, загрузки чанков и автоматической логистики.
