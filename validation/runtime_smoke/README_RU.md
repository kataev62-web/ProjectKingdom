# RC #69: установка и игровая приёмка (10–15 минут)

**Только отдельный тестовый профиль и копия мира. Не production и не готовый релиз.**

## Состав и получение
Artifact GitHub Actions **kingdom-rc-smoke** содержит НОВЫЙ JAR этой RC-сборки, `SHA256SUMS`, `manifest.json`, runner и lock модов. Чужие JAR не распространяются. В manifest указаны commit сборки и точные исходные SHA:
- PR #67: `67fbe6796dacab90c1ae391a945577366454c569` (включает #56, #57, #64).
- PR #66: `43ac75f34aa1c555e71dcbc1bf944223eaebce13` (только исправление регистрации кузницы).
- PR #61, #59 и будущие изменения #68 не включены.

После скачивания распакуйте archive и выполните `sha256sum -c SHA256SUMS`. `commit` — точный commit, который собрал CI (в PR может быть временный merge commit GitHub); это не слияние в main. Свежая сборка создаётся `./gradlew test build`, затем `python3 validation/runtime_smoke/package.py`. Старый artifact #64 больше не используется как источник JAR. SHA конкретного скачанного JAR берите из его manifest, не из отчёта другого прогона.

**Клиент:** Java 17, отдельная установка Minecraft 1.20.1 / Forge 47.3.0. В `mods` только тестового профиля положите RC JAR, TFC 3.2.26, Create 0.5.1.j и Patchouli 1.20.1-85-forge. Моды скачивайте с официальных проектов Modrinth по `mods.lock.json`; там закреплены URL, версии и SHA-512. Flywheel/Registrate вложены в Create. Не добавляйте второй JAR Kingdom другой версии.

**Временный сервер:** тот же набор версий и Java 17. Runner требует Linux/bash и Python 3.11+, проверяет Java, SHA JAR, обязательные modId и контрольные суммы, устанавливает официальный Forge. Диапазоны версий дополнительно проверяет Forge при запуске. Без личного принятия https://www.minecraft.net/eula допустима только подготовка:

```bash
python3 run.py --root /tmp/kingdom-rc-NEW --jar ./kingdomnpc-0.1.0-stage0-voice3.3.jar --sha256 SHA_ИЗ_MANIFEST --commit COMMIT_ИЗ_MANIFEST --prepare-only
```

Для старта владелец должен явно принять EULA; замените `--prepare-only` на `--accept-eula` и укажите **новую пустую папку**. Согласие в одном тесте не устанавливает флаг в CI. Runner не принимает существующий мир/сервер и не удаляет файлы. Он создаёт disposable мир, слушает только loopback/случайный порт, проверяет Done/list и сразу штатно останавливает сервер. Это автоматическая проверка запуска, не multiplayer-сервер для игрока. Результат — `result.json`, `inventory.json`, `console.log`, `install.log`; успех только при ready=true, list_response=true, exit=0. Таймаут по умолчанию 240 секунд. TLS не отключается; HTTP(S)_PROXY передаётся Java, в облаке используется локальное доверенное хранилище среды.

Для игровой приёмки используйте отдельную клиентскую копию уже настроенного TFC-мира либо согласованный тестовый multiplayer-сервер с подтверждённой авторизацией и теми же модами. Подготовка мира/предприятий не входит в 15 минут. Не отключайте защиту/авторизацию и не выдавайте землю/монеты ради обхода условий.

## Проверка игроком
1. **0–3 мин, кузница:** сделайте backup и запишите остатки. Откройте зарегистрированную кузницу, проверьте действующее ядро, объём здания и доступ NPC к реальным TFC forge/anvil. Настройка/диагностика/выбор рецепта должны одинаково видеть регистрацию; перемещённый core, чужая земля, горн за пределами комнаты и выгруженный чанк дают конкретный отказ. Общий каталог изделий и очередь заказов не обещаются этой RC.
2. **3–5 мин, лесоруб:** при готовом законном задании и настоящем TFC-топоре NPC начинает рубку, сохраняет старый инструмент и физически относит брёвна; полный склад сохраняет груз у NPC.
3. **5–8 мин, шахтёр:** проверьте начало проходки и установку настоящих TFC-опор из склада. Чужая/арендованная земля и незагруженный участок запрещают работу; правила обрушений не обходятся.
4. **8–10 мин, животновод:** проверьте настоящий корм, молодых/взрослых животных, familiarity cap и загон на границе чанков. Отказ на чужой земле и отсутствие обработки выгруженных животных обязательны.
5. **10–12 мин, зарплата:** при реальном долге работодатель платит через ПКМ по зарплате NPC. Стоимость монет в его кошельке уменьшается на сумму, полученную NPC; частичная выплата сохраняет остаток, полная снимает паузу. Повторный клик не оплачивает погашенный долг.
6. **12–15 мин, рестарт:** штатно сохраните/закройте тестовую копию, запустите снова. Сравните монеты, долги, груз с NBT, инструмент, профессию, регистрацию кузницы и назначения. При сбое прекратите операции, сохраните latest.log/debug.log/crash-reports, координаты и точные шаги; не повторяйте платёж вслепую.

## Граница подтверждения
Изолированный dedicated startup и автоматические тесты не равны действиям NPC или входу клиента. На стенде нет копии пользовательского настроенного мира и вошедшего игрока. Ковка по реальному нагретому металлу, валка, опоры, кормление, зарплаты и рестарт старого мира остаются ручной приёмкой. Результат локального нового RC-JAR записан в `validation/runtime_smoke/evidence.json`; результат startup именно скачанного CI-JAR и ссылка на artifact — в итоговом описании PR.

При прежнем smoke встречались: необязательный Distant Horizons mixin target, стандартные исправления конфигов, Forge-служебные библиотеки без mods.toml; TFC объяснял предупреждение RuntimeDistCleaner/Screen и продолжал загрузку recipe manager. Ошибка получения ключа Yggdrasil означает непроверенный вход игрока; online-mode не отключается. Ни одно такое предупреждение нельзя молча считать подтверждённой игровой совместимостью.
