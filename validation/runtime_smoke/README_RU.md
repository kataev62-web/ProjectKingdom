# Project Kingdom: тестовый JAR PR #64, Forge + TFC + Create

Это тестовая интеграция PR #56 + #57, не production-релиз. В архиве GitHub Actions `kingdom-runtime-smoke`: JAR, SHA256SUMS, manifest.json, этот файл, run.py и mods.lock.json. Чужие моды не распространяются; runner скачивает их с Modrinth по проверяемым SHA-512. Источники: проекты TerraFirmaCraft, Create и Patchouli на Modrinth; установщик Forge — maven.minecraftforge.net.

## Установка и автоматический smoke (Linux, Python 3.11+, Java 17)
1. Скачайте artifact `kingdom-runtime-smoke` со страницы Actions связанного PR и распакуйте в отдельную папку.
2. `sha256sum -c SHA256SUMS`. Сверьте commit в manifest.json с проверяемым HEAD PR. Ничего не копируйте в production.
3. Введите **значения из manifest.json**, а не условные строки ниже:

```bash
python3 run.py --root /tmp/kingdom-smoke-NEW --jar ./kingdomnpc-0.1.0-stage0-voice3.3.jar --sha256 SHA256_ИЗ_MANIFEST --commit COMMIT_ИЗ_MANIFEST --prepare-only
```

Runner требует НОВУЮ пустую папку. Подготовка устанавливает Forge 1.20.1-47.3.0, TFC 3.2.26, Create 0.5.1.j, Patchouli 1.20.1-85-forge (Flywheel/Registrate вложены в Create). Проверяются контрольные суммы, Java 17, имена обязательных модов; окончательную проверку диапазонов версий выполняет Forge при старте. Установка не равна успешному запуску. При сетевой ошибке/плохой сумме/отсутствующем моде runner завершится с ошибкой.

Для автоматического старта владелец сначала должен принять https://www.minecraft.net/eula. Затем запустите ту же команду с **другой новой папкой**, заменив `--prepare-only` на `--accept-eula`. Флаг означает личное подтверждение владельца; CI его не устанавливает. Runner создаёт новый временный мир, привязывает сервер только к 127.0.0.1 на случайном порту, ожидает Done, запрашивает list, посылает stop и сохраняет result.json, inventory.json, console.log, install.log. Он не принимает существующий сервер/мир, не удаляет и не перезаписывает production. Только ready=true + list_response=true + exit=0 означают успешный startup smoke; JUnit не заменяет эту проверку.

Нужны сеть и доступ к Modrinth CDN, Maven Forge, официальным Minecraft libraries/данным. Runner передаёт стандартные HTTP(S)_PROXY в Java; в данной облачной среде использует её локальное доверенное хранилище сертификатов. TLS не отключается. При непригодном прокси/сертификате исправьте окружение, не снимайте проверки. Аргумент --timeout задаёт предел ожидания запуска (по умолчанию 240 секунд).

## Игровая проверка 10–15 минут — только копия мира
Автоматический стенд намеренно сразу останавливается и не предназначен для подключения игрока. Для игровой проверки подготовьте отдельную клиентскую инсталляцию Forge 47.3.0 с JAR Kingdom и точными модами из mods.lock.json; в Windows скопируйте их в mods отдельного тестового профиля. Используйте резервную копию уже настроенного TFC-мира/предприятия (его подготовка не входит в 15 минут). Для multiplayer нужен отдельный безопасно настроенный тестовый сервер с теми же версиями и подтверждённой EULA; случайный порт smoke-runner не является публичным сервером. Никаких автоматических whitelist/OP/обходов авторизации runner не делает.

1. 0–2 мин: создайте резервную копию; зафиксируйте версии, монеты, долг и содержимое складов; откройте существующую Книгу/меню NPC. Не выдавайте себе землю или деньги ради обхода прав.
2. 2–5 мин: в готовом законном лесном предприятии поручите лесорубу работать. Проверьте замену старого инструмента на настоящий TFC-топор, физическую валку и поступление брёвен; полный склад не должен уничтожать груз.
3. 5–8 мин: у существующей шахты проверьте начало проходки, реальные материалы TFC-опор и отказ за пределами владения/загруженного участка. Не разрушайте чужие блоки командами.
4. 8–10 мин: в назначенном загоне проверьте кормление молодых/взрослых животных реальным кормом. Частичная выгрузка соседнего чанка не должна давать доступ к чужим животным.
5. 10–12 мин: при существующем долге нажмите ПКМ по зарплате NPC от имени работодателя: монеты списываются физически, NPC получает ту же стоимость, частичный платёж сохраняет остаток, полный снимает паузу. Повторный клик не оплачивает долг повторно.
6. 12–15 мин: штатно сохраните/закройте копию мира, перезапустите. Сравните монеты, груз/NBT, инструмент, долг, профессию и назначения с записью до остановки. При сбое прекратите тест, сохраните latest.log/debug.log/crash-reports и опишите точные шаги/координаты. Не повторяйте финансовую операцию вслепую.

## Фактический результат 18.11.2026
Владелец явно подтвердил EULA в чате. Запущен оригинальный JAR artifact CI PR #64 (run 44356001242, commit 00ace4ef9d00c2ddcba3b7b7525418d0cf6badea), SHA-256:
`370cbbcb9ddb690e44c5efda98965e1a6a5ea6f746c17937938feb2359c90434`.
Новый CI проверяет текущую ветку, скачивает и повторно упаковывает именно этот исходный runtime-проверенный JAR #64 с проверкой SHA-256. manifest.json различает commit JAR и packaging_commit; чужие моды не включаются. Если исходный artifact истечёт/будет удалён, упаковка завершится ошибкой: нельзя молча заменить его другим JAR.

На новом изолированном мире: TFC Common Setup, Create и реестры загрузились, Minecraft сообщил Done, list вернул 0 игроков, stop сохранил все измерения; result = ready:true, list_response:true, exit:0. Доступ игрока, сетевой игровой протокол/handshake, TFC NPC-валка/проходка/кормление и рестарт пользовательского мира НЕ ПРОВЕРЕНЫ: копии настроенного мира/подключённого клиента нет.

Предупреждения: отсутствующий опциональный Distant Horizons mixin target; создание стандартных конфигов; Forge-служебные JAR без mods.toml. Сообщение RuntimeDistCleaner об отсутствии клиентского Screen немедленно сопровождается пояснением TFC Helpers «This is fine» и успешным захватом recipe manager, сервер не остановлен. Ошибка `Failed to request yggdrasil public key / AuthenticationUnavailableException / Connection refused` остаётся сетевым ограничением; online-mode не отключался, вход игрока не подтверждён. Не считать такой результат полноценной игровой приёмкой.

В этой задаче изменены только runner/его проверки/пакетирование и CI. main, профессии, экономические решения, server/**, Settlement*, склад Kilo и кузнец Ники не менялись. Чужие моды/миры не закоммичены.
