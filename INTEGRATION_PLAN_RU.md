# Один путь вместо нескольких конкурирующих систем NPC

1. **MineColonies как исполнитель:** житель, навигация, строительство, заказы, рабочее место, инвентарь, колония. Не менять его vanilla/собственный AI через `setNoAi`.
2. **Kingdom как управляющая модель:** UUID, пол/возраст, родство, найм, зарплата, права на территорию, государства, торговые сделки.
3. **Авторитет данных:** работа/путь/строительство и запасы колонии — MineColonies; финансы, юридические права, родство — Kingdom. Не копировать значения без схемы синхронизации.
4. **Ключ связки:** UUID физической сущности гражданина плюс ID колонии/ID гражданина через настоящий API фиксированной версии. При перезапуске сверка UUID, запрет дубликатов.
5. **Производство TFC/Create:** только штатные рецепты и станции; не заменять 3 пшеницы -> хлеб без полного процесса. Адаптеры должны проверять права, состояние, доступность чанков и транзакции предметов.
6. **Версионность:** перед API-вызовами закрепить точный релиз MineColonies 1.20.1 + Structurize, MultiPiston, BlockUI, Domum Ornamentum. Форк только если API недостаточно, с GPLv3-комплаенсом; ассеты не копировать.
7. **Контроль качества:** автономная колония строит дом, фермер производит реальные TFC культуры, курьер перемещает инвентарь, аренда запрещает чужую работу, перезапуск не дублирует ресурсы. Это критерии будущих этапов, пока НЕ пройдены.
