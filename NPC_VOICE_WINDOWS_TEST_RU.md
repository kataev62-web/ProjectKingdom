# Голосовое общение с NPC — проверка на Windows

## Установка исправления voice1

Версия в списке модов должна быть `0.1.0-stage0-voice1`. Полностью закройте клиент и остановите сервер. Уберите прежний JAR Project Kingdom из обеих папок `mods`, затем установите один и тот же новый JAR на клиент и сервер. Остальные моды оставьте на месте. Перезапустите оба процесса.

Сначала проверьте ответ обычным текстовым обращением `Имя, как дела?`: реплика NPC должна появиться в облаке даже без микрофона. Затем проверяйте запись клавишей V. Озвучка требует доступного русского системного голоса Windows; его отсутствие не должно возвращать ответы NPC в чат.


## Что входит в сборку

Для клиента и сервера используется один JAR мода. Русская модель распознавания Vosk уже находится внутри него: отдельный голосовой модуль, Python, сервер распознавания и ручная установка модели не нужны. Голос обрабатывается на компьютере игрока; на сервер отправляется только готовый текст.

Поддерживаемая платформа первого выпуска: Windows 10/11 x64, Minecraft 1.20.1, Forge 47.3.0 и Java 17. Сервер может быть выделенным: клиентские голосовые классы на нём не запускаются.

## Как говорить

1. Посмотрите на NPC с расстояния не более 8 блоков.
2. Удерживайте клавишу V и произнесите фразу по-русски. Клавишу можно переназначить в настройках управления как «Говорить с NPC».
3. Отпустите V. Над панелью предметов последовательно появятся состояния «Слушаю…» и «Распознаю…».
4. При доступном русском голосе Windows NPC ответит голосом, а точный текст появится в облаке над NPC, не в чате.

Если прицел не попал в NPC, можно назвать его в начале фразы: «Анна, как дела?». Сервер всё равно заново проверяет NPC, расстояние, права, инвентарь, деньги и задержку между запросами.

## Первый запуск

При первом запуске встроенная модель размером около 46 МБ проверяется по SHA-256 и автоматически распаковывается в `kingdomnpc/voice-cache`. Поэтому первая подготовка распознавания может занять заметно больше времени. При следующих запусках используется проверенный кэш.

Мод использует выбранный в Windows микрофон по умолчанию и штатный русский голос Windows. Никакая отдельная программа Project Kingdom не устанавливается. Если Windows не предоставляет русский голос или доступ к микрофону, текстовый диалог и облако над NPC продолжают работать без озвучки.

## Ручная проверка

- Запустите клиент Windows с единственным JAR в папке `mods`.
- Разрешите Java доступ к микрофону в параметрах конфиденциальности Windows.
- Встаньте в пределах 8 блоков, наведитесь на одного NPC, удерживайте V 2–4 секунды и скажите: «Как твои дела?».
- Убедитесь, что в обычном чате не появилась реплика NPC.
- Убедитесь, что над нужным NPC появилось читаемое русское облако и прозвучал голос.
- Отойдите от говорящего NPC: громкость должна уменьшаться. Перейдите с одной стороны NPC на другую: направление звука должно измениться.
- Быстро получите две реплики одного NPC: новая реплика должна заменить старое воспроизведение.
- Проверьте разговор обычным чатом и правым кликом: прежние способы общения должны сохраниться.

## Если голос не работает

- «Микрофон недоступен»: проверьте микрофон по умолчанию и разрешение Windows для настольных приложений/Java.
- «Речь не распознана»: говорите ближе к микрофону, без музыки на фоне, и удерживайте V до конца фразы; запись ограничена 8 секундами.
- Облако есть, звука нет: штатный русский голос Windows недоступен либо аудиоустройство не открыло WAV. Диалог при этом уже принят сервером и не теряется.
- Долгое состояние при первом запуске: дождитесь проверки и распаковки встроенной модели; повторные запуски используют кэш.

Реальный микрофон, установленный голос Windows и конкретное аудиоустройство требуют этой ручной проверки на целевом компьютере; автоматические тесты проверяют упаковку, безопасность команд, границы очереди и весь маршрут сообщений.

## Проверка исправлений 26 октября

- Удерживайте V дольше восьми секунд: запись должна завершиться автоматически и отправиться один раз; отпускание клавиши не создаёт второй запрос.
- Во время записи откройте меню или переключитесь в другое окно: запись отменяется.
- Выйдите из мира во время распознавания и войдите снова: старая фраза не отправляется на новый сервер.
- Получите несколько ответов одного NPC подряд: старые ожидающие реплики отбрасываются, остаётся последняя.
- Выйдите из мира во время подготовки озвучки: отложенный голос не должен прозвучать после выхода или в другом мире.
- Во время озвучки повернитесь, отойдите и измените громкость «Общая»/«Дружелюбные существа»: направление и громкость меняются; при нулевой громкости воспроизведение прекращается.

Это сценарии для ручной проверки на Windows. Автоматические проверки не подтверждают работу реального микрофона и установленного системного голоса.
