# Project Kingdom 1.8.0 — Towny-inspired Cities & Nations

Исходный проект Forge 1.20.1, продолжение 1.7.0. Это **не готовый JAR**.

## Что реализовано в исходниках

- Сохранение городов и наций в SavedData; связь игрока с городом; мэр и правитель.
- Владение чанками города, зонирование: жилое, торговое, промышленное, ферма, военное, общественное.
- Разрешения: мэр, арендатор (через API), общественный доступ только на использование; строительство и разрушение чужими запрещены по умолчанию.
- Проверка права на ВСЮ площадь проекта архитектора перед созданием строительного задания.
- В игровом меню «Города и нации»: основание города и нации, назначение зоны, переключение общественного доступа.
- Защита от захвата уже закреплённого за другим игроком чанка через существующий KingdomTerritories.
- Данные сохраняются в NBT и переживают перезапуск (реальная загрузка в игре не проверена).

## Как открыть

Shift + ПКМ с компасом → «Города, нации и участки». Основать город, затем «Территории» → закрепить чанк.

## Не реализовано / не проверено

- ForgeGradle сборка, запуск клиента и сервера; нужны реальные игровые тесты.
- Налоги, банковские транзакции, рынок, аренда за деньги: **не активны**, чтобы не создавать фиктивные деньги.
- Военный ИИ, осады, дипломатия, NPC-мэры, автономное основание городов и готовые схематики Structurize.
- Полная блокировка всех Minecraft-событий (включая взрывы и сторонние моды): пока проверка прав применяется к действиям меню и строительным проектам, не является полноценным антигрифом.
- Старые личные приваты не мигрируют автоматически в города: данные сохранены в старом реестре, для новых городских прав требуется отдельная миграция.

## Техническое решение

Towny — Paper/Bukkit плагин, **не включён** в Forge сборку. Использованы принципы: Town → Nation, чанковые участки, zoning, permission policy. Новая модель: `KingdomCivicsData.java`. Поддержка сохранений через Minecraft SavedData. Лицензионно безопаснее реализовывать идеи независимо, чем копировать исходники Towny.
