# Ручная сверка грузовых операций

Команды доступны только оператору с правами 2+:

- `/knpc supply-recovery inspect <UUID>` — просмотр реестра и незавершённой операции.
- `/knpc supply-recovery resolve <UUID> PICKUP 0` — подтвердить, что забор товара НЕ произошёл.
- `/knpc supply-recovery resolve <UUID> PICKUP N` — подтвердить фактический полный забор N предметов.
- Аналогично `DELIVERY` для разгрузки. N должен совпадать с количеством незавершённой операции.

**Перед resolve обязательно вручную сверить**: исходный сундук продавца, сундук покупателя, инвентарь NPC и инвентарь повозки. `resolve` не создаёт и не перемещает предметы. Частичная операция не может быть закрыта этой командой — сначала физически исправьте состояние. Старые записи без базовых счётчиков требуют отдельной миграции.

Это не обеспечивает атомарность сохранения Minecraft при аварии. Даже после закрытия журнала возможна несогласованность NBT NPC/телеги и SavedData: нужен игровой тест и восстановление на резервной копии мира.
