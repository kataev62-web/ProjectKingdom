# Project Kingdom 1.9 — единая ветка разработки

Продолжение 1.8, не отдельный мод. Minecraft 1.20.1, Forge 47.3.0.

## Реально добавлено в исходный код
- Forge обработчики разрушения, размещения, взаимодействия и взрывов в городских чанках (остальной мир не блокируется).
- Депозит одного настоящего изумруда из инвентаря через меню в казну города; мэр может перевести средства в казну нации.
- Сохранение отношений союзников наций; метод проверки отношений RESIDENT/NATION/ALLY/OUTSIDER.
- Старые системы 1.8 (меню, архитекторские заказы, реестр отрядов, зоны) сохранены.

## Важно: что ещё НЕ реализовано
- Полная защита от всех модовых действий, поршней, жидкости, огня, механизмов Create и обходных путей. Не использовать как антигриф без тестов.
- Настоящий ИИ армии и строительных NPC, рабочие схемы Structurize, автоматическая экономика, ежедневные налоги и дипломатический интерфейс.
- Автономное проектирование зданий архитектором и фактическая обработка рецептов TFC.
- ForgeGradle компиляция и испытание в клиенте: не выполнены. Код требует сборки и исправления возможных API-несоответствий.

## Порядок проверки
1. Собрать на Java 17 через `01_build_windows.bat` с доступом к ForgeGradle.
2. Запустить копию мира, проверить создание города и чанка через Shift+ПКМ с компасом.
3. Проверить чужого игрока: разрушение, установка, ПКМ по сундуку, взрыв.
4. Проверить внесение изумруда и перезапуск сервера.

Никакие сторонние исходники Towny или Ancient Warfare не копировались. Использованы идеи из публичной документации.
