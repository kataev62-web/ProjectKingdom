# Книга игрока — первая страница персонажа

Требование: **социальный статус, действующая должность, титул и гражданство
видны сразу при открытии книги** (вкладка «Игрок», открыта по умолчанию).

## Левая страница
- Имя персонажа и значок игрока.
- **Социальный статус:** ранг по действующей экономической прогрессии (1–9).
- **Должность:** только действующее назначение в городе. Мэр берётся из
  реестра текущего мэра, дополнительные должности из муниципального реестра.
  Если должностей несколько, показана основная и число дополнительных;
  наведение курсора показывает полный список.
- **Титул:** действующий правитель государства либо фактический основатель
  поселения. Экономический ранг сам по себе **не** является юридическим титулом.

## Правая страница первого разворота
- Город гражданства и государство (если есть).
- Репутация в городе и общественное положение.
- Городская награда и государственный орден.
- Краткий итог личных предприятий и купленных участков.

Никакие данные с этих страниц не наделяют игрока правами — права определяют
сервис городов и административный реестр непосредственно на сервере.

## Ограничения и проверка
- Данные пересчитываются **при каждом открытии** книги. Изменение должности
  во время просмотра будет видно после закрытия и нового открытия книги.
- Число наёмных NPC передаётся в снимке, но для аккуратной верстки
  первой страницы оставлено в данных; расширенный список активов
  может появиться на вкладке «Капитал».
- Строки не должны выходить за границы двух страниц на разных GUI Scale.
- Для обновлённого сетевого формата установлен протокол Kingdom `3`;
  устаревший JAR клиента не должен ошибочно читать новое содержимое.
- До тестового релиза необходимо визуально проверить экран Minecraft 1.20.1
  и правильность отображения многодолжностного чиновника, мэра, основателя,
  правителя государства и обычного гражданина.
