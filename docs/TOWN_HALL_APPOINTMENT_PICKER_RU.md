# Ратуша — выбор игрока или NPC при назначении должностей

Городская ратуша → вкладка «Должности» (только действующий мэр/основатель).

Интерфейс **без ввода UUID**:
1. Кнопка «Игроки / NPC» выбирает тип кандидата.
2. На экране три человека с именами; стрелки листают список.
3. Нажать на кандидата, затем выбрать должность стрелками.
4. «Назначить» или «Снять» изменяет реальные юридические записи города;
   для назначения мэра доступна только кнопка «Назначить» и только основателю.
5. После успешного изменения окно закрывается, чтобы новая версия списка и
   полномочий загружалась через свежий снимок сервера.

Имена офлайн-игроков берутся из GameProfileCache, NPC — из сохраняемого реестра
`KingdomNpcData` (UUID `Worker.entityId`). NPC должен быть совершеннолетним,
состоятельным в данном городе по документированному месту проживания:
членство в `KingdomCivicsData`, привязанный к городу дом или его серверная
принадлежность поселению. Совершеннолетнего NPC, живущего в городе, можно
внести в список граждан при первом законном назначении; чужого NPC нельзя.
Назначение не переписывает владения на землю.

Сервер повторно сверяет законность конкретного назначения и актуального мэра,
город, факт существования кандидата, данные открытого меню и дистанцию
до зарегистрированной ратуши. Неизвестные UUID, истёкшие права управления,
кандидаты чужих поселений и устаревшие пакеты отклоняются.

Поддерживаемые роли: мэр, казначей, земельный управляющий, судья,
начальник стражи, управляющий складом.

Снимок содержит максимум 256 кандидатов в одном городе. Если в большом
городе людей больше, потребуется серверная постраничная выборка.

**Техническое ограничение:** само назначение должности не создаёт автономную
логику чиновника: для самостоятельных действий NPC нужна отдельная
интеграция с соответствующими сервисами. Интерфейс назначает полномочия,
не создаёт монеты или бесплатных работников.
