# Project Kingdom — штатные NPC + объём груди и юбка (26.10.2026)

## Новое утверждённое решение
**Не используем** 12 сложных GLB v14–v17. Все NPC остаются **vanilla Minecraft Villager** с прежним AI, торговлей, профессией, экономикой и анимациями. Визуально только зарегистрированным **женщинам 18+** добавляется дополнительный дешёвый геометрический слой:
- две небольшие детали закрытой блузы для естественного объёма груди под одеждой;
- объёмная зелёная юбка из трёх постепенно расширяющихся уровней и пояска;
- одна маленькая текстура 64×64 `textures/entity/female_outfit.png`.
**Предметов и корзин в руках нет. Головы / лица / волосы штатных жителей не заменены.** 
Обычные деревенские жители, NPC мужского и неизвестного пола, дети и подростки остаются без нового слоя.

## Как активировать
У NPC с сохранённым Kingdom worker ID:
1. На тестовом сервере: `/knpc spawn farmer` (использовать ID из сообщения).
2. Администратор: `/knpc gender <id> female`.
3. Клиент и сервер должны иметь **одинаковый обновлённый JAR**; сетевой протокол 5.
4. Теперь NPC получит геометрический слой через пакет 22. При смене пола NPC на `male` слой исчезнет.

## Технические детали
- Клиент: отдельный Forge RenderLayer в существующем Vanilla VillagerRenderer; регистрируется через `EntityRenderersEvent.AddLayers` и `RegisterLayerDefinitions`.
- Сервер: для действительных Kingdom worker UUID рассылает флаг; при начале слежения сразу, при изменении возраста/пола проверяет каждые 80 тиков.
- Принципиально **без новых NPC entities и без зависимостей от сторонних модов**. Не требуется GeckoLib/Blockbench/GLB. Новая геометрия рендерится только на клиенте, в том же JAR.
- Тестовый JAR создаёт GitHub Actions при успешной сборке.
- Нужно проверить визуальное сочетание платья с ванильной одеждой и оригинальными руками жителя, масштабы разных профессий, чанки, ночное освещение.

## Граница готовности
Эта ветка предназначена для CI и игрового теста; публикацию в main проводить только после успешного запуска в клиенте Minecraft Forge 47.3.0. **Никакой физический сервер не изменяется при коммите в GitHub**. Для сервера и Windows-клиента необходимо скопировать JAR и перезапустить. Желательно резервная копия мира перед обновлением.
