# Stage 0 Game Core — отчёт проверки

Дата: 2026-10-21

## Объём

Проверяется фундамент игрового ядра: идентичность аккаунта/персонажа/династии, сохранение, одноразовая авторизация, миграции, политика спавна, постоянная Книга, представление финансов, изоляция модулей и отключённая граница платежей.

## Уже подтверждено

- Компиляция основного Forge-кода: успешно.
- JUnit: 19 тестов, 0 ошибок, 0 падений.
- Stage 1 logic harness: успешно — сохранение денег, торговля, контракты NPC, зарплаты, налоги, миграционные снимки.
- Stage 1 workshop harness: успешно — реальные рецепты, время, запасы, физические входы/выходы, покупки NPC, сохранение и загрузка.
- Статическая проверка структуры и обязательных компонентов: успешно.
- Чистая Forge-сборка `clean test build`: успешно; создан reobfuscated JAR.
- Dedicated-server smoke-test: успешно; Forge 47.3.0 загрузил мод и мир до `Done (16.107s)` без исключений мода.
- Целостность JAR: `unzip -t` не обнаружил ошибок.

## Ограничения проверки

- Внешний лаунчер и реальная платформа авторизации не входят в этот Forge-репозиторий; `TokenVerifier` требует будущего адаптера.
- Платёжный провайдер намеренно отключён и не может изменить баланс.
- Клиент доходит до запуска Forge, но интерактивная отрисовка не проверена: в среде нет X11/Wayland и `xvfb-run`, поэтому GLFW штатно сообщает `Unable to initialize GLFW` до загрузки клиентского UI.
- Тестировать установку следует только на копии мира.
