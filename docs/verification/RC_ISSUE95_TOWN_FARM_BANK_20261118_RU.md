## Совместимость и границы

- PR #85 и PR #89 используют один домен администраций, но **не редактируют одинаковых файлов**: бывший мэр теряет `TOWN_HALL`, существующая роль казначея остаётся, а банк использует актуальные данные `KingdomAdministrationData`. Не считать это доказательством клиентской авторизации — проверять при ручном подключении.
- PR #88 меняет только фермерские рабочие классы: не меняет городскую SavedData, банк, журнал, общий `KingdomNpcMod`, TFC-кузницу.
- `BankOperationLedger` ведёт **отдельный файловый журнал**, не заменяет NBT/региональные файлы атомарным единым коммитом и после сомнительного прерывания **должен оставлять карантин**, а не автоматически выплачивать деньги.
- **Не включено**: PR #72/#74/#91 (кузница Codex), #90 (склад Kilo), #59/#70 MiniMax, #76/#86 физическая касса с нерешённым alias-wrapper риском. Никакие связанные исходники не менялись.
- Требуются реальные Forge 47.3.0/Minecraft 1.20.1/TFC/Create сценарии: открытая ратуша до/после смены мэра, TFC семена/урожай и реальный склад, физический сейф/монеты при рестарте **копии** мира. CI сборка и NBT round-trip не доказывают crash atomicity, вход в игру и работу NPC.
