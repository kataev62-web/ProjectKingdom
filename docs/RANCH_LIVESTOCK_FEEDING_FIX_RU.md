# Животновод — исправление подсчёта и кормления (31.10.2026)

## Диагностика

В меню загона `KingdomLivestockWork.inspect()` при ошибке интеграции с
TFC или отсутствии загруженного центрального чанка возвращал нули —
не отличая **«животных нет»** от **«данные недоступны»**.
Кроме того, подсчитывал только животных, которые соответствовали
`TFCAnimalProperties`, игнорируя животных других модов и Vanilla.

NPC-животновод в автономном цикле сам кормил голодных TFC животных.
TFC разрешает кормление раз в игровые сутки; после кормления NPC
попытка игрока не принималась. Существующая функция выбора участка
проверяла только старые территории `KingdomTerritories`, но не участки,
приобретённые в современной системе городов Kingdom.

## Исправления

1. Загон в подсказке показывает **всего живых животных**,
   **животных TFC**, **других животных**, количество голодных TFC,
   готовность молока, шерсти и яиц.
2. Данные отображаются многострочной подсказкой у иконки загона.
   Для загонов на незагруженных чанках вместо нуля пишется
   **«Животные: НЕИЗВЕСТНО. Не все чанки загружены»**.
   При недоступном API TFC показывается отдельное предупреждение.
3. Автокормление — отдельная кнопка (пшеница) в меню загона,
   **по умолчанию ВЫКЛЮЧЕНО**, включая все старые сохранения.
   Включается только явным согласием управляющего. Все старые
   настройки забоя и сбора яиц остаются без изменений.
4. Игрок кормит TFC животных привычным способом:
   **Shift + ПКМ с подходящим видом корма**, когда животное
   снова голодно (обычно следующий игровой день).
   Мод не перехватывает нажатие по животному.
5. Регистрация нового загона проверяет современный городской титул,
   аренду либо законно выданные права на землю, а для участков без
   городской записи — старые территории Kingdom. Все клетки квадрата
   проверяются, чужие участки не допускаются.

## Проверка в клиенте

- Сначала сохраните копию мира.
- Откройте зарегистрированную ферму → «Поля и семена» →
  «Животноводство». Наведите курсор на загон: проверьте цифры.
- На загоне с животными TFC проверьте `Автокормление: ВЫКЛ`.
- Возьмите подходящую еду TFC и используйте Shift + ПКМ по
  голодному животному. Если его уже кормил NPC сегодня —
  попробуйте после наступления следующих игровых суток.
- Если написано «чанки не загружены», подойдите ближе к загону,
  затем откройте меню фермы заново.
- На новом законно купленном участке попробуйте регистрацию
  с двумя углами на одной высоте.

**Ограничение:** автокормление не заменяет TFC-совместимые продукты
и не кормит Vanilla животных. Для работы NPC по-прежнему нужны
привязанные склады, настоящий корм, назначенная профессия и рабочий
контракт. CI не заменяет живой тест Forge 1.20.1/TFC.
