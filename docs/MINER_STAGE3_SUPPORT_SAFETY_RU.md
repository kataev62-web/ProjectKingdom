# Шахтёр — проверка креплений TFC

## Реализовано в исходниках

- Проверка настоящего блока по реестровому ID `tfc:wood/horizontal_support/<wood>`.
- Проверка блока породы по нативному тегу `tfc:can_trigger_collapse`.
- Проверка поддержки породного блока снизу: твёрдый неколлапсирующий блок.
- Проверка горизонтальной опоры в радиусе TFC: 4 блока по X/Z и 1 блок вверх/вниз.
- Если порода может запустить обрушение и не поддержана, шахтёр не добывает её и показывает причину в меню.
- Вертикальные балки, заборы и декоративные блоки не принимаются за горизонтальную опору.
- Добавлен unit-тест распознавания настоящих TFC horizontal support block IDs.

## Важное ограничение

Этот коммит реализует защитную проверку, но **ещё не автоматическую установку балок NPC**. TFC требует корректной конструкции: вертикальные балки должны стоять на основании, а горизонтальная балка соединяет две вертикальные, расстояние между которыми не превышает пяти блоков. Только горизонтальная балка создаёт зону защиты. Поэтому нельзя безопасно разместить один горизонтальный блок в центре узкого тоннеля и считать шахту укреплённой.

## Следующая часть

1. Спроектировать штрек шириной 3 блока с карманами для вертикальных стоек.
2. Проверить фактические состояния blockstate вертикальных/горизонтальных балок TFC 3.x (MC 1.20.1).
3. Шахтёр берёт реальные предметы `tfc:wood/support/<wood>` со склада и строит две стойки с соединяющей балкой через штатную логику размещения.
4. После установки проверить через блоки/теги фактическое наличие горизонтальной опоры в зоне.
5. Только затем разрешать добычу пород с `tfc:can_trigger_collapse`.
6. Игровой тест выполнить в копии мира с включёнными TFC collapses.
