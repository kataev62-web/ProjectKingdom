# Project Kingdom — режим администратора, управление NPC-городами

**Версия:** Forge 1.20.1, один JAR Project Kingdom. Все команды выполняются только на сервере. Добавлено в ту же систему `/kingdom`, без MineColonies.

## Включение роли

1. Выдай игроку Minecraft-операторские права уровня **4** (на выделенном сервере через `/op <ник>`, либо разреши команды в одиночном мире).
2. Игрок вводит `/kingdom admin`: команда **переключает режим** «Игрок ↔ Администратор».
3. Эквивалентные явные команды: `/kingdom admin on`, `/kingdom admin off`; проверка: `/kingdom admin status`.
4. Права OP-4 **никогда не выдаются этой командой**. Режим сохраняется после перезахода, но без операторских прав он бесполезен. Консоль сервера имеет полномочия администратора всегда. Действия записываются в журнал `/kingdom admin audit` (последние 15).

## Работа с городами и NPC

NPC предварительно должен быть зарегистрирован в Kingdom и быть совершеннолетним (18+). Его номер **#ID** отображается в меню жителя. Это именно постоянный Kingdom-NPC, не обычный незарегистрированный ванильный житель.

| Команда | Действие |
|---|---|
| `/kingdom admin city list` | Список городов с UUID, мэром и основателем |
| `/kingdom admin city create Avalon_Test 7` | Создать новый город: NPC #7 — первоначальный основатель **и мэр** |
| `/kingdom admin city claim <UUID>` | Закрепить за городом **текущий чанк** администратора; чужую землю нельзя перезаписать |
| `/kingdom admin city mayor <UUID> 7` | Назначить NPC #7 мэром указанного города |
| `/kingdom admin city founder <UUID> 7` | Назначить NPC #7 основателем/владельцем поселения |
| `/kingdom admin kingdom list` | Список королевств |
| `/kingdom admin kingdom create My_Kingdom 7` | Создать королевство; NPC #7 должен быть мэром своего города, пока не входящего в королевство |
| `/kingdom admin kingdom ruler <UUID> 7` | Назначить NPC #7 правителем существующего королевства; NPC должен состоять в одном из его городов |

Правило: один NPC или игрок может **основать только одно поселение**. Назначение мэра **не передаёт автоматически принадлежащие игрокам земельные титулы**. Административная должность и личная собственность — разные понятия.

Под `founder` сейчас понимаются **реестровые права основателя**, а не автоматический ИИ-поведенческий цикл «владелец NPC принимает решения». Функция самостоятельного строительства и найма NPC-правителем должна быть реализована и протестирована отдельно в Этапе 4 «Автономная жизнь NPC». Назначение не создаёт NPC, не выпускает денег, не строит мэрии и не загружает чанки.

## Удаление городов и королевств

Нельзя удалять города одной случайной командой. Сначала требуется проверка:

1. `/kingdom admin city preview <UUID>` (или `kingdom preview`).
2. Сервер проверяет состояние. Если удаление допустимо, выдаёт **уникальный 8-символьный одноразовый код** с временем действия 2 минуты.
3. `/kingdom admin city delete <UUID> <код>`, аналогично для `kingdom`.
4. Повторно проверяются права, деньги, долги и земельные обязательства. Если данные изменились, сервер **откажет**.

Ограничения удаления:
- **Город:** казна 0, реальные банковские/казначейские резервы 0, отсутствие старых финансовых обязательств, аренд, продаж, долгов, персональных земельных титулов и судебных дел. Незавершённые сделки расширения должны быть сверены. Чужой legacy-claim нельзя очистить вместе с городом.
- **Королевство:** казна 0, нет ни одного входящего города; сначала расформируй его города.
- Удаление **не разрушает блоки** Minecraft и не удаляет физические сундуки. Оно удаляет запись города/королевства, его незащищённые участки/членство и соответствующие административные записи. Перед удалением обязательно делай резервную копию мира.
- Любая операция записывается в отдельный журнал администратора, который переживает удаление города.
- При спорных активах необходимо сначала выполнить явный перенос или урегулирование через соответствующие системы. Удалять их принудительно ради очистки списка запрещено.

## Проверка

1. Сделать копию сохранения Avalon.
2. Назначить OP уровень 4. Проверить, что не-OP не видит команды `/kingdom admin`.
3. Переключить режим вкл/выкл и убедиться, что команды в выключенном режиме не исполняются.
4. Зарегистрировать взрослого NPC, создать тестовый город от его имени, посмотреть `city list` и отметить чанк через `city claim`.
5. Назначить другого NPC мэром; убедиться, что UUID должностного лица и основателя разные и личные участки не передались автоматически.
6. Создать тестовое королевство от имени NPC-мэра. Убедиться, что королевство не удаляется пока в нём есть город.
7. Проверить отказ при неверном коде и истёкшем подтверждении.
8. Удалить только **пустой тестовый город** без чужих прав и финансовых обязательств. Проверить физические блоки, сохранение чужих земель, журнал и перечень городов после перезапуска.

Автоматические тесты Java не заменяют проверки мира Minecraft. Не проводить тесты массового удаления на единственном экземпляре Авалона.
