# Шахтёр: проект креплений TFC и проверка ресурсов

## Код в main

- `KingdomMineSupportPlan`: 4 комплекта каркасов на каждом горизонте, с шагом 5 блоков вдоль главного штрека (5, 10, 15, 20).
- У каждого каркаса: две вертикальные стойки на расстоянии 2 блоков по X, одна центральная позиция горизонтальной балки на высоте +2, центральный проход свободен.
- `KingdomMineSupportSafety`: TFC-камень, способный спровоцировать обрушение, нельзя добывать без опоры.
- `KingdomMineSupportSupply`: проверяет настоящие предметы `tfc:wood/support/<wood>` в доступном сырьевом складе. Для начала комплекта нужно не меньше 3 штук, но окончательный расход зависит от механики TFC.
- При опасной проходке меню NPC показывает: нет склада, нет балок либо требуется установка каркаса.

## Критически важно

Это **план строительной механики**, а не автоматически построенная TFC-конструкция. Здесь ещё нет нативного размещения `SupportItem` через взаимодействие, нет автоматической выкопки боковых карманов и нет утверждённого игрового теста. Нельзя выдавать наличие трёх предметов за наличие настоящей горизонтальной опоры.

Для полной автономии требуется:
1. Подтвердить точные Java-классы и placement API TFC для 1.20.1.
2. Расширить выработку до 3 блоков только там, где excavation safety это допускает.
3. Подвести шахтёра к месту работ, забрать настоящие support items со склада в инвентарь NPC.
4. Применять настоящие предметы TFC через серверное взаимодействие, **не** `setBlock` произвольных support blockstates.
5. После размещения проверять горизонтальную TFC-опору в мире и гарантировать расход реальных предметов.
6. При недоступной безопасной схеме/неудачном размещении прекращать проходку без генерации предметов.
7. Провести интеграционный тест с включёнными обрушениями TFC в отдельной копии мира.
