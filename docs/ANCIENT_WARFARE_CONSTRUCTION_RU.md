# Project Kingdom — строительство по принципам Ancient Warfare 2

## Совместимость и происхождение

Вдохновение: [Ancient Warfare 2](https://github.com/P3pp3rF1y/AncientWarfare2), мод для Minecraft 1.12.x (GPLv3). Это **самостоятельная реализация** для Kingdom/Forge 1.20.1, без копирования кода/ресурсов AW2 и без зависимости от AW2 или MineColonies.

Система использует уже существующие планы `KingdomBuildingTypes`, права `KingdomConstructionAccess`, SavedData `KingdomConstructionData` и реальный склад материалов. Новые предметы регистрирует `KingdomConstructionRegistry`.

## Крафт (верстак 3 × 3)

| Предмет | Рецепт | Идентификатор |
|---|---|---|
| Чертёжный стол | P P P / P C P / P B P; P — любые доски из `minecraft:planks`, C — верстак, B — книга | `kingdomnpc:drafting_table` |
| Строительный чертёж | пробел P пробел / P C P / пробел P пробел; P — бумага, C — древесный уголь | `kingdomnpc:building_blueprint` |
| Строительный молот | I I I / пробел S пробел / пробел S пробел; I — железный или кованый железный слиток (Forge-теги), S — палка | `kingdomnpc:builders_hammer` |

Дополнительно восстановлены рецепты зарегистрированных блоков `managed_storage` и `demand_board`. Рецепты открываются на сервере при входе игрока через `KingdomRecipeUnlock`; тот же список доступен в datapack advancement.

## Порядок строительства

1. Купите или арендуйте участок с правом строить; права проверяются сервером для каждого блока будущей постройки.
2. Скрафтите **чертёжный стол** и установите его на участке. Старые `minecraft:lectern` остаются совместимыми.
3. Скрафтите **строительный чертёж**, откройте стол без блока в руке, выберите ратушу, дом, склад, кузницу либо таверну. После успешной регистрации стройки **один чертёж израсходуется** (в творческом режиме не расходуется).
4. Установите настоящий сундук или бочку **вплотную** к столу. Через меню проекта посмотрите смету и положите нужные блоки в сундук.
5. **Строитель-NPC:** заключите договор с предприятием, назначьте профессию `builder`. В рабочую смену он приходит на стройку, берет реальный предмет со склада и ставит по одному блоку за цикл.
6. **Игрок:** скрафтите молот, возьмите его в основную руку и нажимайте ПКМ по столу стройки. Один клик продвигает чертёж на одну ячейку: ставит один блок с расходом материала из того же сундука либо учитывает уже правильно поставленный блок. Удачная установка тратит одну единицу прочности молота.
7. **Предпросмотр:** возьмите строительный чертёж и ПКМ по столу активного проекта — следующий блок подсветится частицами и появятся его координаты и тип. Чертёж при просмотре не тратится.

Все изменения происходят на сервере. Нет телепортации блоков, бесконечного склада, автоматического создания строительных материалов, генерации незагруженных чанков или обхода прав собственности. Прогресс проекта сохраняется в SavedData после перезапуска.

## Границы текущей реализации

- Работают пять программно сгенерированных типов зданий. **Импорт файлов `.aws` Ancient Warfare или `.schem` WorldEdit ещё не реализован.**
- Вместо полноценной полупрозрачной 3D-голограммы подсвечивается **следующий блок**, без клиентского рендерера.
- Установленные блоки используют `defaultBlockState`; ориентация лестниц, дверей и сложные блоки TFC требуют отдельной поддержки блок-состояний.
- Материалы для проектных стен пока преимущественно ванильные; подключение шаблонов из TFC и Create — следующий этап.
- NPC-строитель работает с существующей системой трудовых договоров и только в разрешённое расписанием время.
- Нельзя переносить исходники или файлы шаблонов AW2 напрямую, не соблюдая лицензию GPLv3 и не адаптировав их к 1.20.1.

## Проверка

`./gradlew test build --no-daemon`, затем отдельный тест на Forge 47.3.0 с TerraFirmaCraft: проверить регистрацию предметов, отображение моделей, рецепт, создание стройки, расход материалов, сохранение проекта и работу NPC/молота на общей площадке.
