# Project Kingdom — строительство по принципам Ancient Warfare 2

## Совместимость и происхождение

Вдохновение: [Ancient Warfare 2](https://github.com/P3pp3rF1y/AncientWarfare2), мод для Minecraft 1.12.x (GPLv3). Это **самостоятельная реализация** для Kingdom/Forge 1.20.1, без копирования кода/ресурсов AW2 и без зависимости от AW2 или MineColonies.

Система использует уже существующие планы `KingdomBuildingTypes`, права `KingdomConstructionAccess`, SavedData `KingdomConstructionData` и реальный склад материалов. Новые предметы регистрирует `KingdomConstructionRegistry`.

## Крафт (верстак 3 × 3)

| Предмет | Рецепт | Идентификатор |
|---|---|---|
| Чертёжный стол | P P P / P C P / P B P; P — любые доски из `minecraft:planks`, C — верстак, B — книга | `kingdomnpc:drafting_table` |
| Строительный чертёж | пробел P пробел / P C P / пробел P пробел; P — бумага, C — древесный уголь | `kingdomnpc:building_blueprint` |
| Строительный молот | I I I / пробел S пробел / пробел S пробел; I — железный или кованый железный слиток (Forge-теги), S — палка | `kingdomnpc:builders_hammer` |

Дополнительно восстановлены рецепты зарегистрированных блоков `managed_storage` и `demand_board`. Рецепты открываются на сервере при входе игрока через `KingdomRecipeUnlock`; тот же список доступен в datapack advancement.

## Порядок строительства

1. Купите или арендуйте участок с правом строить; права проверяются сервером для каждого блока будущей постройки.
2. Скрафтите **чертёжный стол** и установите его на участке. Старые `minecraft:lectern` остаются совместимыми.
3. Скрафтите **строительный чертёж**, откройте стол без блока в руке, выберите ратушу, дом, склад, кузницу либо таверну. После успешной регистрации стройки **один чертёж израсходуется** (в творческом режиме не расходуется).
4. Установите настоящий сундук или бочку **вплотную** к столу. Через меню проекта посмотрите смету и положите нужные блоки в сундук.
5. **Строитель-NPC:** заключите договор с предприятием, назначьте профессию `builder`. В рабочую смену он приходит на стройку, берет реальный предмет со склада и ставит по одному блоку за цикл.
6. **Игрок:** скрафтите молот, возьмите его в основную руку и нажимайте ПКМ по столу стройки. Один клик продвигает чертёж на одну ячейку: ставит один блок с расходом материала из того же сундука либо учитывает уже правильно поставленный блок. Удачная установка тратит одну единицу прочности молота.
7. **Предпросмотр:** возьмите строительный чертёж и ПКМ по столу активного проекта — появятся 3D-точки недостроенной части здания и отдельная отметка следующего блока. Чертёж при просмотре не тратится.
8. **Совместная стройка:** владелец открывает меню площадки, подходит к другому игроку на расстояние до 8 блоков и нажимает слот «Пригласить в бригаду». Приглашённый игрок может строить молотом и просматривать проект. Повторное нажатие снимает разрешение. Всего до восьми помощников; приглашения сохраняются при перезапуске мира. Управление NPC и запуском стройки остаётся только у владельца.

Все изменения происходят на сервере. Нет телепортации блоков, бесконечного склада, автоматического создания строительных материалов, генерации незагруженных чанков или обхода прав собственности. Прогресс проекта сохраняется в SavedData после перезапуска.

## Границы текущей реализации

- Работают пять программно сгенерированных типов зданий и импорт **Sponge .schem v2/v3** из WorldEdit. Формат `.aws` Ancient Warfare напрямую не поддерживается.
- Предпросмотр показывает ограниченный 3D-контур **частицами**, а не прозрачную текстурную модель каждого блока.
- Для поддерживаемых обычных блоков сохраняются свойства состояний (`facing`, `axis` и т. д.), включая зарегистрированные блоки TFC и Create.
- Из безопасного режима строительства временно исключены двери, кровати, двухблочные растения, падающие блоки и строительные леса: для них необходим отдельный атомарный обработчик установки. Такие схемы отклоняются с сообщением, а материалы не расходуются.
- Содержимое BlockEntity из схем не переносится; сложные машины Create и TFC требуют отдельных игровых испытаний на корректность поведения после размещения.
- NPC-строитель работает с существующими трудовыми договорами и только в разрешённое расписанием время. Игроки-помощники могут строить из общего склада с разрешения владельца.
- Исходники/ресурсы AW2 не копируются: реализация независимая, по концепции мода для Minecraft 1.12.x.

## Проверка

`./gradlew test build --no-daemon`, затем отдельный тест на Forge 47.3.0 с TerraFirmaCraft: проверить регистрацию предметов, отображение моделей, рецепт, создание стройки, расход материалов, сохранение проекта и работу NPC/молота на общей площадке.


## Импорт собственных зданий WorldEdit (.schem)

В игре доступны схемы формата **Sponge Schematic v2 и v3**, сохранённые WorldEdit или совместимым редактором. Старый бинарный формат `.schematic` / `.aws` Ancient Warfare напрямую не поддерживается.

1. Создайте или экспортируйте здание как `<имя>.schem` на Minecraft 1.20.1. Используйте названия из строчных латинских букв, цифр, `_` и `-`, например `avalon_gate.schem`.
2. Скопируйте файл **на сервер**, в папку мира:
   `<папка_мира>/data/kingdom_schematics/avalon_gate.schem`.
   Это серверная папка, а не клиентская директория WorldEdit.
3. Перезагружать мод не требуется. Откройте **чертёжный стол → Архитектор**: рядом с пятью стандартными зданиями появится название схемы. Если схем много, используйте значок компаса для следующих страниц.
4. Возьмите скрафченный `kingdomnpc:building_blueprint`, убедитесь в наличии прав на весь участок, затем нажмите на импортированное название. Схема проверится, а её **неизменяемая копия** запишется в `<папка_мира>/data/kingdom_schematics/.snapshots/`.
5. В меню активного проекта отображаются смета и недостающие материалы. Для просмотра 3D-точек возьмите чертёж в руку и нажмите ПКМ по чертёжному столу. Для строительства — молот или назначенный NPC-строитель. Крафтовый чертёж списывается только после создания проекта.

Важные правила импорта:
- До **48 × 48 × 48** блоков по каждой стороне, суммарно не более **65 536** позиций; файл до **2 МиБ** в сжатом виде.
- Импорт сохраняет свойства блоков `[facing=...]`, `[axis=...]` и т. п. Если мод из палитры отсутствует, схема **отклоняется**, а не превращается в воздух.
- При импорте игнорируются NBT-содержимое сундуков, сущности и биомы; содержимое хранилищ не может создаваться из чертежа.
- Воздух в схеме пропускается, а чужие существующие блоки **не удаляются**. Для постройки нужна подготовленная территория.
- Отклоняются схемы с жидкостями, привилегированными блоками, двойными плитами, дверями, кроватями, двухблочными растениями, падающими блоками и строительными лесами. Это защищает реальные запасы от ошибочного расходования.
- Храните папку `.snapshots` при переносе мира на новый сервер: именно она закрепляет правильную форму незавершённых проектов.
- Подсветка отображает ограниченный **3D-контур частицами** и следующий блок, а не полноценные полупрозрачные модели каждой текстуры. Это сделано для низкой нагрузки и не требует внешних клиентских библиотек.

## Технические компоненты

- `KingdomSchematicLibrary` — читает Sponge v2/v3, проверяет размеры, длины varint, палитру и SHA-256, закрепляет неизменяемые версии схем
- `KingdomBlockStateCodec` — разрешает зарегистрированные состояния блоков Forge/TFC/Create, отклоняет отсутствующие и опасные
- `KingdomConstructionPlans` — одинаково разрешает старые и импортированные чертежи
- `KingdomConstructionWork` — ставит полные BlockState с расходом реальных предметов, используется игроком и NPC
- `KingdomConstructionPreview` — адресная ограниченная подсветка недостроенных блоков для владельца и приглашённых игроков
- `KingdomConstructionData` — постоянный список бригады (не более восьми игроков) с проверками приглашений, владельца и отменённых проектов
