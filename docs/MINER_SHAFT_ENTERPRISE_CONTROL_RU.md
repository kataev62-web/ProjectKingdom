# Project Kingdom — настройки шахты через блок предприятия

## Утверждённая схема

1. Владелец открывает **блок предприятия «Шахта» → «Производство»**. В меню находятся серверные действия:
   - **Разметить центральный ствол** — два угла поверхности, Shift+ПКМ пустой рукой; 3D-объём глубиной из настроек. Минимум 7×7, максимум 12×12. Углы могут иметь разную высоту. **Положение и высота ядра предприятия не ограничивают прямоугольник**; вход автоматически назначается в центре южной стороны, снаружи выделения. Для начала работы вход должен быть свободным и иметь опору под ногами.
   - **Начало проходки:** «Вперёд» либо «Сразу вниз».
   - **Количество горизонтов:** 1–4. По умолчанию **3 горизонта**.
   - **Направление галерей:** север / восток / юг / запад.
2. Для режима «Сразу вниз» сначала выкапывается **весь центральный ступенчатый ствол** до глубины `горизонты × 5` блоков (по умолчанию **15 блоков**). По мере спуска шахтёр ставит лестницы из реального склада через два блока перепада; это НЕ магический телепорт.
3. Только после полной проходки центрального ствола открываются внутренние помещения горизонтов на глубинах 5, 10, 15 (для 4 горизонтов также 20). Затем шахтёр укладывает **деревянный настил шириной 2 блока от каждой стены**, оставляя центральное отверстие и отдельную клетку для продолжения лестничного маршрута, если ниже есть ещё один горизонт.
4. После готовности настила данного горизонта шахтёр начинает **12-блочную добывающую галерею** в выбранном направлении. Настоящие опоры TFC размещаются поперёк выбранного направления, опасные блоки проверяются до добычи.
5. Тип грунта определяет инструмент: лопата для доступного естественного грунта, кирка для камня. Сырьё, лестницы, доски, факелы и балки — **реальные предметы**, не генерируются из воздуха.
6. Меню NPC показывает только текущие сведения и причину остановки. Менять план в нём нельзя. После первой физической добычи или установки конструкций настройки шахты блокируются.

## Важное ограничение

Пока сохраняется существующая **ступенчатая схема спуска по периметру**. Лестницы устанавливаются по контрольным глубинам; полноценный вертикальный непрерывный лестничный колодец и гарантированная AI-навигация по нему не реализованы. При отсутствии безопасной TFC-опоры NPC останавливается. Это не подтверждённый игровой цикл.

## Существующие миры

- Старые настройки без новых тегов получают **3 горизонта / север**.
- Если старый ствол был зарегистрирован как 5×5, он не удовлетворяет новому минимуму 7×7. Его нужно заново разметить **до начала работ**; уже начатую шахту не расширяем автоматически, чтобы не разрушать чужие блоки.

## Тесты

JUnit-тесты обновлены для интервала 5, настила 2 блока и направлений галерей. Наличие коммитов не означает запуск Gradle, Forge и игрового теста с TFC; эти проверки подтверждаются отдельно.
