# Project Kingdom — женские NPC: интеграция в игру (тестовая ветка)

Дата: 23.10.2026. **Статус: source-integrated, НЕ готовый релиз.**

## Что сделано
- Синхронизация ID модели по UUID зарегистрированного Kingdom NPC.
- 12 допустимых вариантов женской внешности, выбор по работе, возрасту и ручному ID.
- Старые миры совместимы: новый `AppearanceId` по умолчанию `auto`.
- Только женщины 18+ используют взрослые модели; дети и подростки остаются с обычным рендером. Мужчины и NPC без установленного пола также не изменяются.
- Исходники клиентского рендера Forge 1.20.1, базовая анимация конечностей, визуальное имя и безопасное возвращение к ванильному жителю при отсутствии меша.
- Новый пакет сетевого протокола 4, ID 22; клиент и сервер обязательно должны использовать одну новую сборку.

## Обязательные игровые ресурсы, ПОКА НЕ в GitHub

Скрипт и исходные ресурсы находятся в отдельном ранее созданном архиве `ProjectKingdom_Female_NPC_GAME_INTEGRATION_v11.zip`. Перед сборкой нужный контент из `ProjectKingdom_Female_GamePack_v11/src/main/resources` надо скопировать без изменений:
- `assets/kingdomnpc/models/entity/female_v11/*.pkmesh.gz` — 12 файлов;
- `assets/kingdomnpc/textures/entity/female_v11/*.png` — 12 файлов.

БЕЗ этих 24 файлов код может компилироваться, но новые модели не будут отображаться (рендерер специально не отменяет ванильный рендер при отсутствии мешей). Это НЕ полноценно готовый игровой мод.

## Приёмочные тесты
1. Скомпилировать на JDK 17, Forge 47.3.0: `./gradlew test build` или `gradlew.bat test build`.
2. В клиенте `/knpc spawn baker`, `/knpc gender ID female`; NPC должен сменить внешний вид, но сохранить ID, профессию, работу, диалоги.
3. `/knpc appearance ID 05_shveya` и `/knpc appearance ID auto`.
4. 12 видов: верные текстуры, глаза, кожа, объём волос, юбки и рук с разных ракурсов.
5. Изменение возраста на 15 — должен вернуться обычный житель; проверка `elder` для возраста 65+.
6. Перезагрузка сервера и повторный вход сохраняют ручной вариант.
7. Чужие деревенские жители, дикие NPC, мужские персонажи — без изменений.
8. Открытые миры, слабый ПК, скопления 25–50 NPC: FPS, загрузка чанков и лаги.
9. Проверить обычные таблички имени, Forge-шейдеры, TFC/Create и перезагрузку ресурсов F3+T.
10. Прогон `test`/сборка не означает успешную проверку игры: требуются скриншоты именно из клиента.
