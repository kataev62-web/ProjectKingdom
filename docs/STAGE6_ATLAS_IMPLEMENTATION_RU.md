# Project Kingdom — этап 6: атлас границ и предприятий (23.10.2026)

## Реализовано в исходниках

- В книге персонажа разделы «Мир» и «Государство» содержат единую кнопку «Карты Kingdom».
- Главное меню «Project Kingdom → Карты Kingdom» — единая точка входа: общая графическая карта, политическая карта, карта предприятий, земельная карта и административное планирование города.
- Ванильные пустые и заполненные карты больше не открывают Kingdom по Shift+ПКМ: их действие не перехватывается модом.
- Современный графический атлас реализован в `KingdomGraphicAtlasScreen` с видимым участком 23 × 15 ячеек; прежний `KingdomWorldAtlasMenu` (54 слота, 7 × 4) сохранён только как совместимый код, не как основной интерфейс.
- Слои: земля, политическая карта (города / государства), предприятия.
- Панорамирование, масштабы 1 / 4 / 16 / 64 чанка на ячейку, выбор и сведения о регионе.
- Информация о городских участках берётся из KingdomCivicsData; о государствах — из его же реестра Nations.
- Предприятия отображаются только при наличии активного установленного ядра в KingdomEnterpriseData.
- Изменения обновляются при открытом меню раз в 40 игровых тиков; синхронизация стандартными слотами ChestMenu, без отправки всей карты мира.
- Действующие меню земельных сделок и администратора тоже периодически перечитывают серверную карту.
- Не передаются секретные данные экономики, точные координаты руд и балансы предприятий.
- В карту не добавлены полномочия на регистрацию земли или финансовые операции.

## Что не реализовано

- Отображение на ванильном предмете-карте не требуется: все карты по решению проекта находятся внутри собственного интерфейса Kingdom.
- Отдельное развитие: топографическая карта с детальной геометрией дорог, мостов, зданий и текстурами TFC. Графический атлас уже имеет масштабирование, легенду и маркер игрока.
- Генерация главного NPC-королевства и независимых NPC-деревень как готовых государственных образований.
- Межизмерительные маршруты и межрегиональная топография.
- Непосредственное игровое QA: только GitHub Actions build/test, отдельно требуется ручная проверка Minecraft Forge 1.20.1.

## Архитектурные границы

Не создавать отдельную базу города или предприятия внутри UI и не копировать туда авторитетную собственность. Инвентарное меню хранит только локальную область просмотра / слой / выбранную клетку, а все реальные владения считывает заново из источника.

При расширении города изменяется KingdomCivicsData. Новые данные читаются следующей серверной перерисовкой (в пределах 40 тиков). Графический атлас и обычный предмет «карта» не предоставляют прав на строительство, освоение, покупку или разглашение геологических залежей.

Масштаб 64 чанка на клетку объединяет несколько городов или предприятий. Названия «Несколько городов» и счётчик предприятий позволяют избегать ложного впечатления, что в регионе только одно владение.

## Проверка

- KingdomWorldAtlasSnapshotTest — города, государства, предприятия, разные измерения, отрицательные координаты, объединение чанков на масштабе.
- Полную сборку и результаты тестов проверять в разделе GitHub Actions / Build Project Kingdom.
- Для игрового QA: два игрока открывают карту; первый выкупает чанки через ратушу; второй видит смену цвета открытого атласа. Проверить аналогично создание активного предприятия и назначение города к государству.
