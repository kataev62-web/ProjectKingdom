# Установка отдельного мода «Градостроитель»

Нужны два JAR одинаковой сборки:

1. `kingdomnpc-0.1.0-stage0-voice3.3-ai1.jar` — основной Project Kingdom.
2. `kingdom-city-architect-0.1.0-ai1.jar` — отдельное дополнение.

Оба файла положите в папку `mods` клиента и Forge-сервера 1.20.1. Старую копию
каждого JAR предварительно удалите. Дополнение не запускается без основного мода.

После запуска войдите с уровнем прав 4, призовите личного помощника и
зарегистрируйте ратушу и кузницу. Основные команды:

- `Помощник, проложи дорогу от ратуши до кузницы`
- `Помощник, составь план города`
- `Помощник, подтверди этап`
- `Помощник, покажи следующий этап`
- `Помощник, пересчитай этап`
- `Помощник, отмени разметку`
- `Помощник, статус плана города`

Сначала появляется шерстяная разметка. Стройка начинается только после зелёной
галочки или команды подтверждения. Один тик меняет не более 16 блоков; чанки
принудительно не загружаются. Если строительство остановилось, прогрузите район
плана и повторите действие.
