# Project Kingdom — женские NPC: данные и штатная 3D-модель

Дата: 26.10.2026. Статус: **кодовая интеграция для Forge 1.20.1**; фактический игровой рендер подлежит визуальной проверке.

## Итоговая схема
- NPC остаётся сущностью vanilla `minecraft:villager`, все рабочие механики, поведение и профессии не заменяются.
- Пол сохраняется на сервере в `kingdom_npc_v1` -> `Worker.gender`. Значения: `unspecified`, `female`, `male`; возраст в `Worker.ageYears`.
- Только если это **зарегистрированный Kingdom Worker, женщина, возраст от 18**, сервер отправляет клиентам флаг женского облика.
- Клиент отображает оригинальную модель жителя с женской 64×64 UV-текстурой (лицо, волосы, платье); поверх — геометрия закрытой груди и юбки, с согласованным цветом.
- 4 варианта волос/платьев выбираются по стабильному UUID NPC. Это **варианты рисунка**, не 4 отдельных меша.
- Мужчины, подростки, дети, обычные жители, NPC не из Kingdom не изменяются.
- Пол не определяется по текстуре: текстура является результатом сохранённого `Worker.gender`, не источником данных.

## Как управлять
- Администратор: меню NPC -> «Управление NPC» -> слот 11 «Пол» -> ЛКМ для циклического изменения `не указан → женщина → мужчина → не указан`.
- Команда `/knpc gender <id> female` для существующих NPC, `/knpc identity <id>` для проверки.
- Команда `/knpc spawnfemale <profession>` создаёт **нового** NPC с `gender=female` и 25 годами.
- При смене пола/возраста сервер сразу отправляет состояние существующим наблюдателям. Вход новых игроков синхронизируется при начале отслеживания NPC.
- NBT сохраняется при рестарте мира, предусмотрен автоматический миграционно-безопасный default `unspecified` для старых сохранений.

## Ресурсы
- `textures/entity/female_skin_0.png` ... `female_skin_3.png`: голова/нос/волосы/одежда по ванильной UV-развёртке VillagerModel.
- `textures/entity/female_outfit_0.png` ... `female_outfit_3.png`: цветные юбки и грудь под закрытой блузой.
- Разрешение всех PNG: 64×64, RGBA.
- Пакет остаётся одним JAR без зависимостей от внешних библиотек, Minecraft 1.20.1 Forge 47.3.0 Java 17.

## Проверки перед выдачей релиза
1. `./gradlew test build` на актуальной `main`, с JDK 17.
2. В клиенте реальный показ NPC (лицо, волосы, платье, бюст и юбка), в т.ч. повороты, анимации ног, закрытие головы/нос стандартного жителя и отсутствие Z-fighting.
3. Смена пола в меню и командой, выход и повторный вход, рестарт сервера: gender остаётся female, облик не сбрасывается.
4. Изменить female -> male и возраст до 17: женский облик должен исчезнуть, без затрагивания трудового договора.
5. Профессии, чат/голос NPC, TFC и Create, отображение на расстоянии; оценка FPS при 50 NPC.
6. Клиент и сервер должны использовать один и тот же JAR (сетевой протокол остался 5).

Никаких утверждений о полном визуальном совпадении с концептом до игрового теста.
