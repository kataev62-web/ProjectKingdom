# Project Kingdom NPC 1.3.0 — мост MineColonies (первый этап)

Это **исходный проект**, не собранный JAR. Он расширяет существующую ветку Kingdom NPC 1.2.0.

## Что уже реализовано
- Сохранены прежние системы Kingdom NPC (найм, меню, территория, склады, тестовая работа).
- Добавлено безопасное определение наличия MineColonies и распознавание его сущностей-жителей по ID.
- Команда `/knpc colonies` показывает количество и имена ближайших жителей MineColonies (24 блока).
- Работа MineColonies не перехватывается: автономные AI, колонии, здания, склады и профессии продолжают управляться самим MineColonies.
- Без MineColonies мод Kingdom NPC по-прежнему должен работать независимо.

## Чего ПОКА НЕТ
- Превращения жителей MineColonies в наши Kingdom NPC, общего найма/зарплаты и собственности.
- Автономного основания колонии с полноценной работой по TFC/Create.
- Интеграции складских API MineColonies, его строительных чертежей и реальных рабочих AI.
- Подтверждённой Forge-компиляции и теста запуска данного изменения.

## Установка / сборка
1. Разместить исходники в `D:\ProjectKingdom\development\KingdomNPC_MineColonies_1.3.0`.
2. Из предыдущего рабочего проекта перенести `gradlew.bat`, `gradlew`, папку `gradle`.
3. Выполнить `gradlew.bat clean build --no-daemon`.
4. В отдельном резервном тестовом мире заменить старый `kingdomnpc-*.jar` в `D:\ProjectKingdom\game\mods` на `build\libs\kingdomnpc-1.3.0.jar`.
5. Пока MineColonies не установлен, `/knpc colonies` сообщает об этом; после установки мода и обязательных зависимостей показывает жителей в радиусе 24 блоков.

## Архитектурное решение
MineColonies сохраняет физические сущности, задания и логистику. Kingdom NPC постепенно добавляет социальный и экономический слой поверх API MineColonies, НЕ создаёт их дублей. Версию MineColonies и зависимости фиксируем перед добавлением compileOnly-адаптера. Отдельная лицензия и ограничения ресурсов MineColonies: код GPLv3, ассеты ARR; не встраиваем чужие текстуры/модели в архив.

Источник API: https://github.com/ldtteam/minecolonies
