# Project Kingdom — актуальная разработка (01.11.2026)

**Единый Minecraft-мод**: Minecraft 1.20.1, Forge 47.3.0, Java 17, версия исходников `0.1.0-stage0-voice3.3`.

Исходный код: `src/main/java/ru/projectkingdom`. Точка входа `KingdomNpcMod`. Актуальная CI-сборка: GitHub Actions `Build Project Kingdom`, артефакт `kingdomnpc-stage0`. Не устанавливайте старый `dist/kingdomnpc-0.1.0-stage0-dev.jar`.

## Архитектура
- Собственные города, территории, банк, физические монеты, предприятия, рынки, склады, профессии NPC, строительство и карты Kingdom.
- TerraFirmaCraft и Create используются как игровые технологии и источники настоящих блоков, предметов и рецептов.
- **MineColonies исключён**: не требуется ни для NPC, ни для строительства, ни для склада.
- Все финансы и предметы физические; SavedData хранит юридические права и журналы, но не заменяет материальные запасы.
- Книга Kingdom и единые серверно-авторитетные меню — вход в системы.
- Офлайн-распознавание Vosk и 162 записи Ogg — для русских NPC.

## Состояние
Последние исходники **компилируются в CI**, но игровые сценарии Forge/TFC, клиентский интерфейс, звук, лизинг недвижимости и автономность NPC требуют отдельного тестирования. Успех JUnit — не доказательство готового публичного сервера.

## Как собрать
```bash
./gradlew clean test build --no-daemon
python3 03_verify_project.py
```
Артефакт версии `voice3.3` берите из `build/libs` или из последнего успешного GitHub Actions. Остановите клиент и сервер и замените **единственный одинаковый JAR** с обеих сторон. Сначала резервная копия мира.
