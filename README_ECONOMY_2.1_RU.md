# Project Kingdom 2.1 — экономика, исходники

## Реализовано в этой версии
- Серверный перевод **100 медных** между двумя находящимися рядом игроками с кошельками, через игровое меню. Баланс списывается и зачисляется без создания монет.
- Меню «Кошелёк» → «Переводы игрокам поблизости» (до 18 игроков в радиусе 8 блоков).
- Получение **100 медных** из городской казны в кошелёк, только мэром.
- Внесение **10 медных** в городскую казну как добровольный городской сбор.
- Предыдущие функции физических монет, пополнения кошелька и городских/национальных казначейств сохранены.

## Важно: что НЕ реализовано
- NPC пока используют старую тестовую систему учёта изумрудов: зарплаты, торговлю NPC, автоматические налоги и снабжение армии ещё нельзя считать переведёнными на монеты.
- Ставка платежа пока фиксирована в интерфейсе: 100 медных.
- Городской сбор добровольный, а не автоматическое списание.
- Кошельки должны находиться в инвентаре обоих игроков.
- Сборка Forge и тест в Minecraft НЕ выполнены. Нельзя считать JAR готовым.

## Установка
Это полный исходный проект, не JAR. Для компиляции нужен Java 17, ForgeGradle и доступ к зависимостям. Вызов `gradlew build` возможен после подготовки Gradle Wrapper. Проверять в копии мира.
