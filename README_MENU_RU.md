# Project Kingdom 1.7.0 — управление через меню

Minecraft 1.20.1, Forge 47.3.0. **Исходники, не проверенный JAR.**

## Открытие

В игре возьми обычный компас и нажми **Shift + ПКМ**, держа его в руке. Откроется главное меню Project Kingdom (стандартное окно Minecraft на 27 слотов). Чат-команды для базовых действий не требуются.

## Реализованные серверные действия

- Строительство: выбрать один из 3 типоразмеров дома; проверка всей площади на права владельца; запись проекта и сметы, без появления блоков из воздуха.
- Проекты: просмотр своих проектов с координатами и статусами.
- Армия: создание реестра отряда, переключение приказов. **Солдаты не создаются и приказы ещё не исполняются игровым ИИ.**
- Территории: закрепление чанка 16x16 под текущей позицией; чужой чанк захватить нельзя.
- Жители: переход к существующему интерфейсу NPC (ПКМ по жителю).

## Ограничения

Это первая реализация меню на серверно-авторитетном vanilla ChestMenu. Полноценные экраны с 3D предпросмотром, выбором точного места, схематики Structurize, автоматическое строительство, AI архитектора, армия в мире, интеграция TFC и Create ещё не реализованы. В игре и ForgeGradle проект пока не проверен. Нельзя считать сборку готовой к установке.

## Сборка

Java 17, ForgeGradle, доступ к репозиториям зависимостей. Используй `01_build_windows.bat` из архива. Исходная версия 1.6.0 сохранена отдельно.
