# Project Kingdom 2.0 — валюта Millénaire-типа

Встроено в единый мод, а не отдельный аддон.

- Предметы: медная, серебряная, золотая монеты, кошелёк.
- Курс: 1 / 100 / 10000 медных.
- Кошелёк создаётся из кожи и нити; баланс хранится в NBT предмета.
- Главное меню (Shift+ПКМ с компасом) → «Монеты и кошелёк»: собрать физические монеты, получить монету обратно, перевести 100 медных в казну города.
- Казна города теперь пополняется монетами, не изумрудами; старые балансы из версии 1.9.0 требуют миграции перед реальным серверным запуском.
- Монеты пока выдаются только администратором или в творческом режиме: чеканка из TFC не добавлена, чтобы не создавать бесконтрольную эмиссию.
- Временные текстуры используют стандартные предметы Minecraft; уникальные изображения ещё не нарисованы.
- Нет полноценной торговли NPC, налогов, жалования, меню оплаты другому игроку.
- Проект не компилировался и не тестировался в игре. Это исходники для дальнейшей интеграции.
