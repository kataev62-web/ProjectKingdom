# Avalon — библиотека готовых построек

**Проект:** Project Kingdom / столица Авалон · Minecraft Java **Forge 1.20.1** · TerraFirmaCraft + Create + Chisel-совместимый декор + Domum Ornamentum (без зависимости от MineColonies).

## Зачем нужен этот каталог

После неудачной автоматической застройки Авалона **запрещено** массово расставлять примитивные процедурные дома. Порядок: чистый ландшафт → утверждённая разметка → отбор цельных детализированных схем → тест на отдельном мире → адаптация к рельефу/материалам → только потом вставка в Авалон.

Список внешних работ: [catalog.json](catalog.json). Он фиксирует **кандидатов**, а НЕ уже скачанные или испытанные `.schem`-файлы. На дату 2026-10-23 оригинальные сторонние бинарные схемы сюда не загружены.

## Приоритеты

1. **Жилые и мастерские**: [Stubbs1 / Tom — 80+ builds](https://www.planetminecraft.com/project/medieval-nordic-house-bundle-free-to-use/) (два типа: `INT` с интерьером и `TEM` без интерьера; автор требует указание имени и ссылки). Выбрать 8–12 разных силуэтов, не копировать кварталы целиком без адаптации.
2. **Таверна, док, дом лесоруба и фермера, ворота**: [AntiClimax — 18+ structures](https://www.planetminecraft.com/project/medieval-build-bundle-amp-pack-18-structures/) (есть отдельные схемы с интерьерами; публикация разрешает использование в собственных мирах и на серверах, но **не подтверждает повторную публикацию исходников в нашем GitHub**).
3. **Фасады, домовые модули, фонари**: [Wet — Medieval Build Bundle](https://www.planetminecraft.com/project/medieval-build-bundle-4285671/) (51 дом, 100 вариантов стен; часть поставляется без интерьеров; крупный общий файл вызывает жалобы на OOM).
4. **Колизей**: [KRTQ — Arena 40×40, 1.20.1](https://www.planetminecraft.com/project/arena-medieval-arena-tiny-coloseum-schematic-1-20-1-40x40-blocks/) — проверить трибуны, проходы и функциональность; не увеличивать кольцо процедурно.
5. **Порт**: [TheNewEmpire / ScriptX / IndexOutOfMJ — Medieval Pier 1.18+](https://www.planetminecraft.com/project/medieval-pier/) — проверить доступность скачивания и разрешения; зафиксирована жалоба на неработающую ссылку.
6. **Мельница**: [Bendeeee — Medieval Windmill v2](https://www.planetminecraft.com/project/medieval-windmill-v2/) — 17×32×19, затем адаптировать механизмы Create.
7. **Ратуша**: [Abs0lute- — Medieval Town Hall](https://www.planetminecraft.com/project/medieval-town-hall-6885509/) — с интерьером; проверить блоки, размеры и лицензию.
8. **Замок — пока только референс**: [Nequ — Bohemian Castle](https://www.planetminecraft.com/project/castle-6808690/) — указаны проблемы на 1.20, много display entities и специальные текстуры; **не одобрено к импорту в Forge 1.20.1**.

## Стандарт качества для принятия схемы

- 1.20.1: без блоков более новых версий и отсутствующих модов; блок-палитра проверена **по файлу**, а не по описанию.
- Фундамент привязан к рельефу. Нет висящих в воздухе этажей, обрезанных лестниц, пандусов в никуда.
- Дом выглядит убедительно **с первого лица**, не только с высоты. Крыша многослойная, фасад детализирован, пропорции соответствуют соседям.
- Внутри есть вход, проходы, лестницы, свет, функциональные помещения; у мастерских — место под Kingdom NPC/склад/кассу.
- Проверка в отдельном тестовом мире; сохранение скриншотов с уровня улицы и сверху до принятия.
- Обязательны точные размеры XYZ, точка вставки и ориентация входа; инвентарь блоков для замены на TFC/Chisel/Domum Ornamentum.
- Для цитадели, порта и колизея обязательно отдельное рассмотрение масштаба и воздействия на рельеф.
- Публичный GitHub: **чужие .schem только при подтверждённом разрешении на перераспространение**. Разрешение «использовать на сервере» само по себе недостаточно. Если прав нет — храним метаданные и ссылку на оригинал, а сам файл импортируем локально с соблюдением условий правообладателя.
- Обязательно указывать автора и источник в `CREDITS.md`, включая производные версии.

## Статусы в каталоге

- `candidate` — рассмотрен по опубликованной странице;
- `needs_permission` — право на републикацию файла не подтверждено;
- `file_received` — проверен реальный файл и checksum;
- `tested_1_20_1` — запуск в модовой сборке проверен;
- `approved_for_avalon` — архитектура, лицензия, интерьер, посадка на участок проверены.

**Важно:** само наличие в каталоге не означает, что стройка уже загружена на сервер, интегрирована с NPC или работает с Create.
