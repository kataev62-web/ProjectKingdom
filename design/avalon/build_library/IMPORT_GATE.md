# Приём схематики для Авалона

## Исходные ограничения

- Minecraft **Forge 1.20.1**.
- TerraFirmaCraft + Create; для декора только те Chisel/Domum Ornamentum блоки, чьи реестровые ID реально присутствуют в модпаке.
- MineColonies не должен определять NPC, города или строительство Project Kingdom. Чисто декоративные блоки разрешены только при наличии соответствующего мода в сборке.
- Размещение на утверждённой разметке, не поверх рельефа: только проверенный фундамент, входы, лестницы, портовые пирсы с допустимой высотой над водой.
- Сторонние здания должны оставаться узнаваемыми и качественными с высоты **Y игрока**, а не только в орто-проекции.
- Функциональная система Kingdom NPC/складов/казны/предприятий выполняется **отдельно** от декоративного импорта схем.

## Дерево каталогов (целевая структура)

```text
design/avalon/build_library/
  README.md

  IMPORT_GATE.md
  CREDITS.md                  # перед первым импортом

    adapted/                  # наши производные, с условиями оригинальной лицензии
    original/                 # созданные специально для Project Kingdom

```

## Проверка каждого оригинального файла

1. Зафиксировать URL **оригинального автора**, имя, условия использования и повторной публикации, версию игры.
2. Получить **сам файл** через ссылку правообладателя; вычислить SHA-256.
3. Распаковать в изолированной директории, проверить лимиты размера и состав архива.
4. Прочитать NBT `.schem` / `.schematic` (Sponge v2/v3 или legacy), проверить `Width/Height/Length`, `Palette`, поворот, смещение начала, полный список blockstate. Отклонить неизвестные ID, материалы >1.20.1, недостающие моды и нежелательные сущности.
5. Открыть на отдельном испытательном мире **Forge 1.20.1** с нашим набором модов. Не вставлять сразу в мир Авалона.
6. Проверить входы, высоту этажей, проходы, помещения, крыши, свет, коллизии и производительность.
7. Сохранить **два реальных скриншота** из Minecraft: с улицы/уровня глаз и сверху.
8. Проверить посадку на утверждённый участок: конкретные X/Y/Z, размер и отступы, фундамент без зависания, мосты/дороги.
9. Записать авторство, версию, лицензию, SHA-256, размеры, материалозамены, решение о принятии и URL исходника.
10. Только после этого перенести отдельную схему в каталог `schematics/` и изменить статус в `catalog.json`.

### Не путать права

- **Free download** не равно право публично перепубликовать исходный файл.
- **Use on server** не равно право загрузить чужую `.schem` в публичный GitHub.
- **CC BY** обычно допускает распространение и производные при соблюдении атрибуции и лицензии.
- **CC BY-SA** дополнительно требует соблюдения ShareAlike для производных.
- **CC BY-NC** не подходит по умолчанию для проекта, предполагающего донаты/монетизацию; до отдельного согласования не включать.
- При отсутствии ясных условий: сохраняем **ссылку на источник**, но НЕ чужой бинарник.

## Управление версиями

Не редактировать рабочий Авалон напрямую. Каждый импорт сначала в отдельный staging world; до принятия формировать `.schem` и запись об авторстве. Никаких заявлений «построено» до проверки запуском игры.

## Первые кандидаты с явно указанной лицензией

- [Seegras — Medieval/Baroque Town](https://www.planetminecraft.com/project/medievalbaroque-town/) — **CC BY-SA**; исходная публикация сообщает, что чужой собор **не включён** по причинам лицензии. Подходит как референс плотной планировки и NPC-магазинов, но целый город не вставлять в Авалон.
- [ArcturusPhoenix — Small Deserted Medieval Castle Complex #1](https://www.planetminecraft.com/project/small-deserted-medieval-castle-complex-1-by-arcturusphoenix/) — автор указывает **CC BY 3.0**, совместимость 1.16.5–1.20.x. Проверить сам архив и масштаб; пока не испытан.
