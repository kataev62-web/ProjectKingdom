# Project Kingdom — объёмные NPC, набор v1

Восемь **настоящих 3D-геометрий** жителей королевства (не плоские скины): фермер, кузнец, торговец, городской стражник, охотник, лекарь, жрец, ткачиха.

## Файлы
- `blockbench/*.bbmodel` — **редактируемые исходники** Blockbench; встроенная PNG-палитра, сгруппированные элементы головы, туловища, рук, ног и снаряжения.
- `geometry/*.geo.json` — Bedrock/GeckoLib-style bone geometry, подготовка к будущему Forge-рендереру.
- `obj/*.obj` + `materials/kingdom_npc_palette.mtl` — универсальные 3D-меши с материалами для Blender и других редакторов. При импорте OBJ сохраняйте относительный путь к MTL.
- `textures/kingdom_npc_palette.png` — общий пиксельный атлас цветов 64×64.
- `manifest.json` — ID, размеры и число геометрических примитивов.

## Масштаб и ориентация
- В источниках Blockbench / geometry: 16 единиц = 1 блок Minecraft; рост базового NPC около 32 единиц (2 блока), отдельно головные уборы и оружие.
- Для OBJ координаты уже переведены в блоки Minecraft; ось Y вертикальна, лицо ориентировано в сторону -Z.
- Rig-группы: `head`, `body`, `left_arm`, `right_arm`, `left_leg`, `right_leg`, `equipment_back`, `equipment_left`, `equipment_right`. Это **точки логического разделения**, а не готовые клипы анимации.

## Ограничения и интеграция
В проекте используется Forge 1.20.1 без GeckoLib-зависимости и текущие игровые NPC отображаются обычным рендерером жителя. Поэтому набор — **подготовленные исходные модели для будущего подключения**, а не активная замена текстур/рендера при запуске мода. Для появления персонажей в игре потребуется собственная система `EntityModel/Renderer` либо согласованная интеграция с GeckoLib, плюс анимации и привязка профессий к персонажам.

Геометрия создана из объёмных прямоугольных частей с дополнительными слоями: одежда, лица, обувь, ремни, волосы, инструменты, шлемы, плащи, аксессуары. Создано автоматически на основе утверждённого общего художественного концепта, а не извлечено из картинки. Это первая техническая версия, рассчитанная на дальнейшую художественную доработку.

## Импорт
1. Откройте нужный `.bbmodel` через **Blockbench → File → Open Model**.
2. Поменяйте одежду / цвет / головной убор, сохраняя названия групп.
3. Для Blender: **File → Import → Wavefront (.obj)**, затем выберите `obj/<имя>.obj`. Если материалы не подхватились — укажите общую MTL в папке `materials`.
4. Для будущего GeckoLib понадобится подключить рендерер, корректно замапить UV и анимации; самостоятельно `.geo.json` не появляется в игре.
