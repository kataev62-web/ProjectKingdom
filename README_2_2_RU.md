# Project Kingdom 2.2 — единая экономика и зарплаты

## Изменения относительно 2.1
- Сохранён весь исходный проект 2.1: кошелёк, монеты, города, нации, армии, схемные проекты, интерфейс.
- Добавлен постоянный реестр трудовых договоров `KingdomPayrollData` с сохранением в SavedData.
- Через меню **Кошелёк → Зарплаты работников города** мэр назначает зарплату соседним игрокам — жителям того же города (10, 100, 1000 медных за игровые сутки); ПКМ увольняет.
- Сервер каждые 1200 тиков проверяет наступление следующего игрового дня и переводит зарплату из казны в кошелёк работника. Платёж не выполняется без средств, без кошелька, при отсутствии игрока или при выходе из города.
- При нехватке денег не создаётся задолженность и не печатаются новые монеты. Пропущенный день оплачивается одним платежом, без бесконечного накопления задолженности.
- Все операции проходят на сервере, договоры сохраняются при перезапуске.

## Ограничения
- Это **зарплаты игроков — жителей города**, а не ещё автоматическая зарплата NPC MineColonies или собственных NPC Kingdom. Подключение NPC и магазинов к денежной системе остаётся задачей.
- Пока нет графического окна ввода произвольной ставки, используются три фиксированные ставки.
- Нельзя считать это проверенным игровым релизом: ForgeGradle и запуск клиента не выполнялись.
- В исходном проекте 2.1 остаются экспериментальные механики; требуются сборка и интеграционные тесты.

## Доступ
Shift+ПКМ с компасом → Кошелёк → Зарплаты работников города. Требуется основанный город, вступивший в него второй игрок и монеты в казне.
